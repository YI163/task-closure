# 责任与决策角色分配（RACI / DACI）

- `method_id`: `raci-daci`
- 索引：`methods/index.json`（本文件是正文，JSON 是机器可读索引）
- `verification_status`: `unverified` ——框架的公开来源已在线核验；本条目步骤尚未在真实任务中执行验证，未验证范围见 §8
- 最近更新：2026-10-14（来源核验原始输出：`reports/METHOD_RESEARCH.md`）

## 1. 解决什么问题

多方参与时「谁做、谁批、谁必须被咨询、谁只需知情」含混，导致重复劳动、越权拍板或事后互相推责。

**预期结果**：一张可执行的角色/决策表：每个关键活动恰好一个最终负责人（A），每项决策有明确的批准者、依据与时间。

## 2. 什么时候用 / 什么时候不要用

### 前置条件（应全部满足才使用）

- 任务涉及两个及以上参与方（人、团队或外部机构）
- 能列出关键活动或关键决策清单（5–15 项）
- 角色分配确实会变化或有分歧（否则不必专门制表）
- 能识别出最终负责的人或决策者

### 不适用（出现任意一条就换方法或降级为轻量清单）

- 只有用户一个人执行与决策——写出责任人是自己的表没有使用价值
- 分工已清楚且被各方确认——重复制表只会增加沟通成本
- 无法识别决策者或组织不允许明确责任——先解决授权问题，否则表格是空文
- 被用作事后追责工具而不是协作工具——会把责任表变成政治工具
- 小任务且外部协作只涉及一次性交付——用一句「谁在何时交什么」即可

## 3. 输入与输出

**输入**

- 参与方清单（含外部方）
- 关键活动/决策清单
- 决策权限说明（用户可自行决定什么、什么必须询问发起人）
- 交付物与时限
- 组织既有角色命名（若必须沿用）

**输出**

- RACI 或 DACI 表（活动 × 角色）
- 决策记录：决策内容、决策人、依据、时间
- 需要请示/沟通的事项清单与话术要点
- 发现项：无主活动、双 A 冲突、有权无责错配

## 4. 执行步骤

1. 列出 5–15 项关键活动或关键决策，不罗列所有琐碎动作
2. RACI：先定每项活动的 A（最终负责/批准者），再定 R（执行）、C（必须被咨询）、I（需知情）
3. DACI：对应为 D（Driver 推动者）、A（Approver 批准者，唯一）、C（Contributor 贡献者）、I（Informed 知情者）
4. 逐行检查：每行有且仅有一个 A；没有「有责无权」或「有权不知情」的错配
5. 把需要批准的时点写进计划（何时、向谁、要什么决定）
6. 与相关方确认；尚未确认的必须明确标注为未确认

## 5. 检查表（做完逐条核对；不能打勾就写「未核验」）

- [ ] 每项关键活动恰好一个 A，没有活动完全无人负责
- [ ] C 的数量受控：被咨询的人确实能影响结论，否则降为 I
- [ ] 用户的决策权限与角色表一致；不需要用户批准的事项没有被写成需要
- [ ] 外部发送、购买、提交、删除等有后果的动作被明确标为需要授权
- [ ] 决策记录含依据与时间，可追溯到具体任务步骤

## 6. 模板（可直接复制到任务记录或对话中填写）

```text
RACI 表（每行恰好一个 A）

| 活动/决策 | R 执行 | A 最终负责 | C 必须咨询 | I 需知情 |
|---|---|---|---|---|
|  |  |  |  |  |

DACI 变体：D 推动者 ____  A 批准者（唯一）____  C 贡献者 ____  I 知情者 ____

决策记录

| 决策内容 | 谁决定 | 依据 | 时间 | 是否需要授权/请示 |
|---|---|---|---|---|
|  |  |  |  |  |
```

## 7. 失败处理

| 失败情形 | 处理动作 |
|---|---|
| 出现两个 A | 由上一层负责人指定唯一 A，并把冲突写入决策记录 |
| 有人被标为 C 却从未被咨询 | 要么实际咨询，要么改为 I，不留虚假承诺 |
| 发现活动无人负责 | 立即分配，或明确写出「当前无人负责」的风险，不靠默认兜底 |
| 决策者缺席导致停滞 | 标为阻塞并升级；AI 不得代他人做决定 |
| 角色表与实际不符（某人已退出） | 更新表并记录变更，不静默修改旧表 |

**未验证范围（limitations）**

- section508.gov 页面给出的是 RACI 在特定场景（无障碍合规）下的应用，未覆盖所有组织变体（如 RASCI、CAIRO）
- Atlassian 的 DACI 是其公开玩法说明，不是行业标准组织发布的规范
- 「一线一个 A」等规则来自公开描述与常见实践，本次未逐条比对 ISO/PMI 正式文本
- 尚未在 Task Navigator 的真实任务中执行验证
